# Цены апгрейда

**Модуль цен ингредиентов апгрейда (инструменты, детали, катализатор, квантовый аккумулятор).**

## Общие сведения

- Подтягиваются лоты с аукциона EXBO (buyout) для фиксированного набора предметов апгрейда; перечень определён в `UPGRADE_ITEMS` (8 предметов).
- Результаты хранятся в in-memory кэше по регионам; TTL отсутствует, запись заменяется при каждом успешном обновлении.
- Обновление инициируется при старте сервера (`onStart`).
- Все пути под префиксом `/api/v1`.

## `GET /upgrade-prices/:region`

Возвращает цены апгрейд-ингредиентов для указанного региона.

### Параметры пути

| Поле     | Описание                     | Тип      | Обязательный |
| -------- | ---------------------------- | -------- | :----------: |
| `region` | Идентификатор региона (только `RU`) | `string` | Да |

### Тело ответа

| Поле        | Описание                                              | Тип                   |
| ----------- | ----------------------------------------------------- | --------------------- |
| `region`    | Запрошенный регион                                    | `string`              |
| `updated_at`| Время последнего обновления (ISO 8601, null при ошибке)| `string \| null`     |
| `prices`    | Массив цен предметов                                  | `UpgradePriceEntry[]`|

`UpgradePriceEntry`:

| Поле          | Описание                                                        | Тип              |
| ------------- | --------------------------------------------------------------- | ---------------- |
| `item_id`     | EXBO ID предмета                                                | `string`         |
| `key`         | Логическое имя предмета (см. таблицу выше)                      | `UpgradeItemKey` |
| `min_price`   | Минимальная цена buyout (null, если лотов нет)                  | `number \| null` |
| `count`       | Количество лотов с buyout > 0                                   | `number`         |
| `energy_price`| Цена за единицу энергии (`min_price / energy`; null, если энергия неизвестна или лотов нет) | `number \| null` |

### Возможные ошибки

- **400** — регион не входит в `SUPPORTED_REGIONS` (на данный момент только `RU`). Возвращается `{ region, updated_at: null, prices: [] }`.
- **503** — кэш для региона ещё не готов. Возвращается `{ region, updated_at: null, prices: [] }`.
