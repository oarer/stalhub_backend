# Игроки

**Модуль профилей игроков, заметок, чёрного списка, популярных/недавних игроков и операционных сессий.**

## Общие сведения

- Профили загружаются из EXBO API и кэшируются в Redis на 5 минут (ключ — регион + имя персонажа в нижнем регистре).
- Заметки (admin-authored role/description) хранятся в Postgres и мёрджатся в ответ при каждом обращении.
- Список «популярных» — в Postgres (счётчик просмотров инкрементируется при каждом запросе профиля); «недавние» — in-memory массив, максимум 10 записей, теряется при перезапуске.
- Чёрный список UUID хранится в in-memory `Set`, загружается из Postgres на старте (`onStart → init()`). Записи в чёрный список и заметки требуют админ-права (`requireAuth`, `requireAdmin`).
- `GET /:region/:character` сливает `clan_history` из Postgres в ответ EXBO-профиля.
- Все пути под префиксом `/api/v1`.

## `GET /player/popular`

Возвращает список самых просматриваемых игроков.

### Параметры

| Поле    | Описание                    | Тип       | Обязательный |
| ------- | --------------------------- | --------- | :----------: |
| `limit` | Максимум записей (по умолчанию 50) | `number`  | Нет          |

### Тело ответа

Массив объектов:

| Поле       | Описание                          | Тип                          |
| ---------- | --------------------------------- | ---------------------------- |
| `uuid`     | UUID игрока                       | `string`                     |
| `username` | Имя персонажа                     | `string`                     |
| `alliance` | Фракция                           | `string`                     |
| `region`   | Регион                            | `string`                     |
| `views`    | Количество просмотров             | `number`                     |
| `role`     | Админ-назначенная роль (или null) | `PlayerRole \| null`         |

### Возможные ошибки

Нет специфичных; чёрный список фильтруется на уровне сервиса.

## `POST /player/blacklist`

Добавляет UUID в чёрный список. Запись мгновенно доступна в in-memory и сохраняется в Postgres.

### Тело запроса (JSON)

| Поле   | Описание    | Тип      | Обязательный |
| ------ | ----------- | -------- | :----------: |
| `uuid` | UUID игрока | `string` | Да           |

### Ограничения

Требуется авторизация + админ-права (`requireAuth`, `requireAdmin`).

### Тело ответа

| Поле      | Описание  | Тип                        |
| --------- | --------- | -------------------------- |
| `success` | Результат | `true`                     |
| `message` | Сообщение | `string`                   |
| `data`    | Данные    | `{ uuid: string }`         |

### Возможные ошибки

- **400** — дубликат UUID в чёрном списке.

## `POST /player`

Создаёт заметку о игроке (роль + описание). Админ-операция.

### Тело запроса (JSON)

| Поле          | Описание    | Тип                   | Обязательный |
| ------------- | ----------- | --------------------- | :----------: |
| `uuid`        | UUID игрока | `string`              | Да           |
| `description` | Описание    | `string`              | Да           |
| `role`        | Роль        | `enum PlayerRole`     | Да           |

Возможные значения `PlayerRole`: `EXBO`, `SCAMMER`, `MEDIA`, `STALHUB`, `SPONSOR`, `HELPER`, `BUGBOUNTY`.

### Ограничения

Требуется авторизация + админ-права (`requireAuth`, `requireAdmin`).

### Тело ответа

| Поле      | Описание  | Тип                                    |
| --------- | --------- | -------------------------------------- |
| `success` | Результат | `true`                                 |
| `message` | Сообщение | `string`                               |
| `data`    | Данные    | `{ uuid, description, role }`          |

### Возможные ошибки

- **400** — дубликат UUID (уникальное ограничение Postgres).

## `GET /player/:region/operations/sessions`

Возвращает список сессий операций из EXBO API (с кэшированием).

### Параметры пути

| Поле      | Описание                            | Тип     | Обязательный |
| --------- | ----------------------------------- | ------- | :----------: |
| `region`  | Регион (`RU`, `EU`, `NA`, `SEA`, `NEA`) | `enum Regions` | Да |

### Query-параметры

| Поле       | Описание                                            | Тип       | Обязательный |
| ---------- | --------------------------------------------------- | --------- | :----------: |
| `username` | Фильтр по имени игрока                              | `string`  | Нет          |
| `limit`    | Лимит записей (0–100)                               | `number`  | Нет          |
| `offset`   | Смещение для пагинации                              | `number`  | Нет          |

### Тело ответа

`OperationSessionListing` — структура, возвращаемая EXBO API.

### Возможные ошибки

- **5xx** — ошибка EXBO API (если кэш пуст).

## `GET /player/:region/:character`

Возвращает профиль игрока из EXBO API с мёрджем `clan_history` из Postgres.

### Параметры пути

| Поле        | Описание                                 | Тип               | Обязательный |
| ----------- | ---------------------------------------- | ----------------- | :----------: |
| `region`    | Регион                                   | `enum Regions`    | Да           |
| `character` | Имя персонажа (регистронезависимый поиск) | `string`          | Да           |

### Тело ответа

Совокупность `PlayerResponse` + поле `clan_history` — массив записей из Postgres:

| Поле            | Описание                       | Тип      |
| --------------- | ------------------------------ | -------- |
| `username`      | Имя персонажа                  | `string` |
| `uuid`          | UUID игрока                    | `string` |
| `status`        | Статус аккаунта                | `string` |
| `alliance`      | Фракция                        | `string` |
| `lastLogin`     | Дата последнего входа          | `Date`   |
| `clan`          | Информация о клане             | `Clan`   |
| `stats`         | Статистика                     | `Stat[]` |
| `role`          | Локальная роль (из заметки)    | `{ role, description }` |
| `clan_history`  | История кланов                 | массив записей (player_name, region, clan_id, clan_name, clan_tag, alliance, rank, joined_at, seen_at) |

### Возможные ошибки

- **5xx** — ошибка EXBO API (кэш пуст или невалидный ответ).

## `GET /player/all`

Возвращает все заметки игроков из Postgres, опционально фильтруя по роли.

### Query-параметры

| Поле   | Описание                        | Тип                | Обязательный |
| ------ | ------------------------------- | ------------------ | :----------: |
| `role` | Фильтр по роли                  | `enum PlayerRole`  | Да           |

### Тело ответа

Массив объектов `PlayerNoteDTO`:

| Поле          | Описание           | Тип                   |
| ------------- | ------------------ | --------------------- |
| `uuid`        | UUID игрока        | `string`              |
| `description` | Описание           | `string \| null`      |
| `role`        | Роль               | `enum PlayerRole`     |

### Возможные ошибки

- **400** — обязательный параметр `role` не передан.
