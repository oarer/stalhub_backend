# Админ

**Модуль администрирования: управление пользователями, артами, бейджами, банами, кланами, уведомлениями, правами и ролями.**

---

## Общие сведения

Все маршруты модуля расположены под префиксом `/api/v1/admin`. Авторизация обязательна: из cookie `access_token` извлекается JWT-сессия (`requireAuth`), затем проверяется наличие пермишнена `user:manage` (`requireAdmin`). Модуль артов использует отдельный guard `requireArtManage` с пермишненом `art:manage`.

**Ранжирование (role rank):** система ролей основана на числовом `rank` — чем выше ранг, тем выше полномочия. Администратор не может мутировать пользователей или роли с рангом ≥ собственного. Проверка `canManageUser` / `canManageRole` запрещает изменения равных и более высокоранговых целей, включая самого себя.

**Логирование банов:** в модуле банов — два раздела:
- `POST /users/:user_id/ban` (см. Пользователи) — ручной бан, запись в `userSettings`, отзыв всех сессий.
- `GET /admin/bans` — только просмотр журнала `banLog` (автоматические + ручные) и агрегированная статистика.

**Auto-ban** (`src/utils/auto-ban/index.ts`): автоматическая система двух ударов (warn → ban) работает параллельно. При первом нарушении — `auto_warned`, при втором — `auto_banned` + `banned`. Пользователи с рангом ≥ `AUTO_BAN_SKIP_RANK` автоматически не блокируются — отправляется alert на ручную проверку. Журнал записывается в `banLog` и доступен через `GET /admin/bans`. Сами auto-ban эндпоинтов не имеет — это middleware/hooks.

## Пользователи

### `GET /admin/users`

Постраничный список пользователей с поиском.

#### Параметры (query)

| Поле     | Описание                                              | Тип      | Обязательный |
| -------- | ----------------------------------------------------- | -------- | :----------: |
| `take`   | Количество элементов на страницу                      | `number` | Нет          |
| `page`   | Номер страницы (с 1)                                  | `number` | Нет          |
| `search` | Поиск по username или name (регистронезависимый)       | `string` | Нет          |

Дефолты: `take = 24`, `page = 1`.

#### Тело ответа

```jsonc
{
  "data": [
    {
      "id": 1,
      "username": "user",
      "name": "Имя",
      "joined_at": "2025-01-01T00:00:00.000Z",
      "roles": [],
      "sessions": [],
      "banned": false,
      "_count": { "sessions": 3, "builds": 12, "articles": 2 }
    }
  ],
  "total_count": 150,
  "page": 1,
  "take": 24
}
```

### `GET /admin/users/:user_id`

Детальная информация о пользователе: настройки, кастомизация, привязки (Discord/Telegram/Exbo), бейджи, роли с пермишненами, счётчики, последние 10 бан-логов.

#### Параметры (params)

| Поле      | Описание  | Тип      | Обязательный |
| --------- | --------- | -------- | :----------: |
| `user_id` | ID юзера  | `number` | Да           |

#### Тело ответа

Объект пользователя со всеми связями, поле `banned` вычисляется (с учётом истекших временных банов).

#### Возможные ошибки

- **404** — пользователь не найден.

## Баны (журнал)

Журнал банов и статистика. Все эндпоинты требуют пермишнен `user:manage`.

### `GET /admin/bans`

Постраничный список записей `banLog` (включая автоматические баны auto-ban).

#### Параметры (query)

| Поле     | Описание                                              | Тип      | Обязательный |
| -------- | ----------------------------------------------------- | -------- | :----------: |
| `take`   | Количество элементов на страницу                      | `number` | Нет          |
| `page`   | Номер страницы (с 1)                                  | `number` | Нет          |
| `auto`   | Фильтр: только автоматические (`true`) или ручные (`false`) | `boolean` | Нет   |
| `rule`   | Фильтр по правилу нарушения (напр. `request_abuse`, `content_spam`) | `string` | Нет |

Дефолты: `take = 24`, `page = 1`.

#### Тело ответа

```jsonc
{

    {
      "id": 1,
      "user_id": 42,
      "rule": "content_spam",
      "severity": "BAN",
      "reason": "Автоматическое предупреждение",
      "meta": {},
      "auto": true,
      "created_at": "2025-01-01T00:00:00.000Z",
      "user": { "id": 42, "username": "user", "name": "Имя" }
    }
  ],
  "total_count": 100,
  "page": 1,
  "take": 24
}
```

## Уведомления

Все эндпоинты требуют пермишнен `user:manage`. Автор уведомлений — `"Администрация"`.

### `POST /admin/notifications/broadcast`

Рассылка уведомления всем пользователям.

#### Тело запроса

| Поле     | Описание                   | Тип      | Обязательный |
| -------- | -------------------------- | -------- | :----------: |
| `title`  | Заголовок                  | `string` | Да           |
| `content`| Текст (до 5000 символов)   | `string` | Да           |
| `type`   | Тип уведомления            | `number` | Нет          |
| `link`   | Ссылка                     | `string` | Нет          |

Дефолты: `type = 0`, `link = null`.

#### Тело ответа

```json
{ "sent": 120, "notification": { "id": 1, "title": "...", "content": "...", "type": 0, "link": null, "author": "Администрация" } }
```

Если пользователей нет: `{ "sent": 0 }`.

## Роли

Все эндпоинты требуют пермишнен `user:manage`. Мутации дополнительно проверяют ранг: создание/обновление роли разрешено только если `rank` новой роли строго ниже ранга актора.

### `GET /admin/roles`

Список всех ролей с пермишненами и количеством пользователей.

#### Тело ответа

Массив объектов: `id`, `name`, `description`, `rank`, `permissions: [{ id, name }]`, `_count: { users }`.

---

### `POST /admin/roles`

Создание роли.

#### Тело запроса

| Поле          | Описание        | Тип      | Обязательный |
| ------------- | --------------- | -------- | :----------: |
| `name`        | Имя роли        | `string` | Да           |
| `description` | Описание        | `string` | Нет          |
| `rank`        | Ранг роли       | `number` | Нет          |

#### Возможные ошибки

- **403** — нельзя создать роль с рангом ≥ собственного.

---

### `PATCH /admin/roles/:id`

Обновление роли.

#### Параметры (params)

| Поле | Описание | Тип      | Обязательный |
| ---- | -------- | -------- | :----------: |
| `id` | ID роли  | `string` | Да           |

#### Тело запроса

| Поле          | Описание        | Тип      | Обязательный |
| ------------- | --------------- | -------- | :----------: |
| `name`        | Имя роли        | `string` | Нет          |
| `description` | Описание        | `string` | Нет          |
| `rank`        | Ранг роли       | `number` | Нет          |

- **403** — нельзя изменить роль с рангом ≥ собственного; новый ранг ≥ собственного.
