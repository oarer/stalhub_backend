# Билды

**Модуль CRUD-операций с билдами (сборками) оружия/артефактов.**

Билды хранятся в сжатом виде (zlib + base64, префикс `v1:`). Максимальный размер сжатого payload — 50 000 байт.

- **Публичные** методы: `GET /builds` и `GET /builds/:id` (с опциональной авторизацией — для поля `is_starred`).
- **Авторизация** (`requireAuth`): `POST /builds`, `PATCH /builds/:id`, `DELETE /builds/:id`, звёзды.
- **Права**: обновление и удаление доступны автору билда **или** обладателю права `builds:manage`.
- **Анти-спам**: при создании проверяется лимит `SPAM_LIMIT_BUILD` (`enforceContentSpam`).

---

## `GET /api/v1/builds`

Постраничный список билдов.

### Параметры (query)

| Поле         | Описание                          | Тип                                      | Обязательный |
| ------------ | --------------------------------- | ---------------------------------------- | :----------: |
| `take`       | Количество элементов на страницу  | `number`                                 | Нет          |
| `page`       | Номер страницы (с 1)              | `number`                                 | Нет          |
| `tags`       | Фильтр по тегам (через запятую)   | `string`                                 | Нет          |
| `sort`       | Сортировка                        | `"newest"` · `"stars"` · `"price"`       | Нет          |
| `price_min`  | Минимальная цена                  | `number`                                 | Нет          |
| `price_max`  | Максимальная цена                 | `number`                                 | Нет          |

Дефолты: `take = 24`, `page = 1`, `sort = "newest"`.

Фильтрация по тегам — OR-логика (билд содержит хотя бы один из указанных тегов). Фильтры по цене и сортировки `"price"` / `"stars"` выполняют полный перебор всех билдов в памяти.

### Тело ответа

```jsonc
{
  "data": [
    {
      "id": 1,
      "external_id": "a1b2c3d4",
      "title": "Название билда",
      "data": { "/* BuildData */" },
      "flags": 0,
      "tags": ["tag1", "tag2"],
      "price": 12345,
      "views": 100,
      "author": { "id": 1, "name": "Имя", "username": "user" },
      "stars_count": 5,
      "is_starred": false,
      "created_at": "2025-01-01T00:00:00.000Z",
      "updated_at": "2025-01-01T00:00:00.000Z"
    }
  ],
  "total_count": 150,
  "page": 1,
  "take": 24
}
```

Поле `price` — суммарная стоимость артефактов из билда по региону `RU`. `is_starred` заполняется только при наличии авторизации.

### Возможные ошибки

Нет (публичный эндпоинт).

## `GET /api/v1/builds/:id`

Получение билда по числовому `id` или `external_id`.

### Параметры (path)

| Поле | Описание              | Тип     | Обязательный |
| ---- | --------------------- | ------- | :----------: |
| `id` | ID или external_id    | `string` | Да           |

### Тело ответа

Объект билда (аналогичен элементу `data[]` из списка, но поле `views` уже включает текущий просмотр). Вызов автоматически инкрементирует счётчик просмотров.

### Возможные ошибки

- **null** — билд не найден (при возврате `null`).

## `POST /api/v1/builds`

Создание нового билда.

### Гард

`requireAuth` — обязательная авторизация.

### Тело запроса

| Поле    | Описание             | Тип       | Обязательный |
| ------- | -------------------- | --------- | :----------: |
| `title` | Название билда       | `string`  | Да           |
| `data`  | Данные билда (BuildData) | `any`  | Да           |
| `flags` | Флаги                | `number`  | Нет          |
| `tags`  | Список тегов         | `string[]`| Нет          |

Ограничение `title`: maxLength 200 символов.

### Тело ответа

Созданный билд (аналогичен элементу `data[]` из списка, `stars_count = 0`, `is_starred = false`).

### Возможные ошибки

- **401** — не авторизован.
- **422** — невалидная структура `data` (ошибка валидации `validateBuildData`).
- `error: "Build data exceeds maximum size"` — сжатый payload превышает 50 000 байт.

## `PATCH /api/v1/builds/:id`

Частичное обновление билда.

### Гард

`requireAuth` — обязательная авторизация. Доступно автору билда **или** пользователю с правом `builds:manage`.

### Параметры (path)

| Поле | Описание | Тип     | Обязательный |
| ---- | -------- | ------- | :----------: |
| `id` | ID билда | `string` | Да           |

### Тело запроса

| Поле    | Описание             | Тип       | Обязательный |
| ------- | -------------------- | --------- | :----------: |
| `title` | Название билда       | `string`  | Нет          |
| `data`  | Данные билда (BuildData) | `any`  | Нет          |
| `flags` | Флаги                | `number`  | Нет          |
| `tags`  | Список тегов         | `string[]`| Нет          |

### Тело ответа

Обновлённый билд (аналогичен элементу `data[]` из списка).

### Возможные ошибки

- **401** — не авторизован.
- **403** — нет прав (не автор и нет `builds:manage`).
- **404** — билд не найден.
- **422** — невалидная структура `data`.
