# Loot

**Каталог дропа (loot-таблиц) STALCRAFT: один эндпоинт, отдающий зашифрованный каталог.**

## Общие сведения

- При старте процесса каталог **один раз** собирается из сырых игровых файлов (директории из `env.LOOT_*`), нормализуется и шифруется AES-256-GCM.
- Если исходников нет или сборка пала, выполняется откат на ранее собранный файл `catalog.enc` из `env.LOOT_OUT_DIR`. Только когда не работает ни то, ни другое, эндпоинт недоступен (503).
- Если задан `LOOT_OUT_DIR`, рядом с `catalog.enc` записывается и открытый `catalog.json`.
- Клиенту отдаётся зашифрованный payload (ключ дешифрования не передаётся — клиент использует собственный секрет). Ответ кэшируется браузером/CDN: `Cache-Control: public, max-age=3600`.
- Внутренних запросов к сторонним API нет — всё собирается из игровых исходников (JSON с комментариями и BOM; trailing-запятые не поддерживаются).

## `GET /api/v1/loot`

Зашифрованный каталог дропа.

### Тело ответа

```json
{
  "alg": "AES-256-GCM",
  "iv": "…",
  "tag": "…",
  "data": "…"
}
```

`iv`, `tag`, `data` — base64. Расшифрованный (`data` после AES-256-GCM) каталог имеет структуру:

- объект, ключ — имя loot-таблицы (или shufflebag);
- значение таблицы — `{ "title"?, "slots": [...] }`, где `title` — локализованные названия (`ru`/`en`/`es`/`fr`/`ko`);
- `slots` — массив слотов; слот — список предметов (вложенный список внутри слота означает альтернативы в одном дропе);
- предмет — `{ "stack"?, "weight", "pct", "names"? }`:
  - `weight` — относительный вес шанса в слоте; `pct` — процент веса предмета от суммы весов слота (0–100, округлённый до 6 знаков);
  - `stack` — `{ "id", "stackSize", "tag"?, "stackSizeVariance"?, "qlt"? }` (качество `qlt` выделяется из тега);
  - `names` — локализованные названия предмета;
  - предмет без `id`/`stack` — пустой дроп.

Shufflebags разрешаются рекурсивно в эквивалентные взвешенные списки предметов; предмет с одинаковым id в разных таблицах — один и тот же предмет каталога.

### Возможные ошибки

- **503** — `{ "error": "loot catalog not available", "details": "<причина>" }` — каталог не собрался и нет готового `catalog.enc`.
