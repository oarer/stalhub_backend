# Модуль /articles

**Статьи StalHub: гайды, квесты и новости. Создание, редактирование, статусы модерации, версии, изображения, звёзды и комментарии.**

---

## Общие сведения

Все пути имеют префикс `/api/v1`.

**Права:**
- `articles:manage` — требуется для создания статей типа `STALHUB`, смены статуса (`/:id/status`), редактирования/удаления чужих статей, удаления чужих комментариев и загрузки изображения в чужие статьи. На `GET /articles` это право расширяет видимость на все статусы (без него — только свои статьи).
- Без права `articles:manage` пользователь видит и редактирует только свои статьи; `GET /articles/public` возвращает только статьи в статусе `APPROVED`.
- Загрузка изображения (`POST /:id/image`) доступна только автору статьи (или админу).

**Жизненный цикл статусов (`ArticleStatus`):** `PENDING` → `REVIEW` → `APPROVED` / `DENIED` / `BANNED`.

- Новая статья создаётся со статусом по умолчанию `PENDING`.
- Автор тумблит статус `REVIEW` ↔ `PENDING` через `POST /:id/submit` (перевод в/из очереди модерации), при этом `status_reason` очищается.
- Смена статуса — административное действие (`PATCH /:id/status`). При `DENIED` или `BANNED` сохраняется переданный `status_reason`; при любом другом статусе причина очищается.
- `DENIED` и `BANNED` отличаются от `PENDING`: модератор может вернуть статью в модерацию, задав любой другой статус.

**Типы статей (`ArticleType`):** `QUEST`, `GUIDE`, `OTHER`, `STALHUB`, `FACTION`. Квест-поля (`quest_name`, `quest_type`, `quest_map`, `reward_text`, `reward_money`, `faction`) сохраняются и возвращаются только для типа `QUEST`, для остальных — `null`.

**Тип квеста (`QuestType`):** `STORY`, `SIDE`.

**Внешний ID:** `external_id` — slug, генерируемый из заголовка; `GET /:id` принимает как slug, так и числовой первичный ключ.

**Просмотры:** `GET /:id` записывает просмотр через дедупликацию (view-dedupe): авторизованный зритель идентифицируется по `user_id`, аноним — по `sha256(ip + user-agent)`, TTL 12 часов (Redis, `SET NX EX`). Уникальный просмотр инкрементирует поле `views` и метрику `content_views_total{type="article"}`. Возвращаемое `views` учитывает возможный прирост.

**Спам-лимиты:** создание статьи и комментария проверяются правилом `enforceContentSpam` (см. `/auto-ban` в общих сведениях): `SPAM_LIMIT_ARTICLE = 10` в час на пользователя, `SPAM_LIMIT_COMMENT = 5` в час.

**Версии:** при создании статьи пишется начальная версия `1.0.0`; при каждом изменении `content` (PATCH/создание с контентом) добавляется новая запись `articleVersion` с меткой `Date.now()` (timestamp) либо явно переданной.

## `GET /articles`
Список статей. Для обычного пользователя — его собственные статьи; при наличии права `articles:manage` видны все статьи всех статусов.

### Авторизация
Требуется `requireAuth` (JWT). Без права `articles:manage` возвращаются только статьи автора.

### Параметры (query)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `take` | Кол-во элементов на странице (по умолчанию `24`) | `number` | Нет |
| `page` | Номер страницы (по умолчанию `1`) | `number` | Нет |

### Тело ответа
```json
{
  "data": [
    {
      "id": 1,
      "external_id": "slug",
      "status": "PENDING",
      "status_reason": null,
      "type": "GUIDE",
      "title": "Заголовок",
      "content": "Текст статьи",
      "image_url": null,
      "quest_name": null,
      "quest_type": null,
      "quest_map": null,
      "reward_text": null,
      "reward_money": null,
      "faction": null,
      "flags": 0,
      "tags": [],
      "views": 0,
      "author": { "id": 1, "name": "Имя", "username": "ник" },
      "stars_count": 0,
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ],
  "total_count": 1,
  "page": 1,
  "take": 24
}
```
Сортировка — по `created_at` (по убыванию). Поля `quest_*`, `reward_*`, `faction` заполнены только для `type = "QUEST"`.

### Возможные ошибки
- **401** — нет авторизации / истёкшая сессия
- **403** — аккаунт заблокирован; гостевой доступ ограничен функционалом клана

## `POST /articles/:id/image`
Загрузка изображения статьи, сохраняется в `uploads/articles/<id>/image/` под UUID-именем с расширением по фактическому типу. Возвращает публичный URL-путь.

### Авторизация
Требуется `requireAuth`. Разрешено только автору статьи или пользователю с `articles:manage` (403 для остальных).

### Параметры (body, multipart/form-data)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `file` | Файл изображения | `file` | Да |

Допустимые заявленные MIME-типы: `image/jpeg`, `image/png`, `image/webp`, `image/gif`. Максимальный размер — `ARTICLE_IMAGE_MAX_BYTES = 10 МБ`; больший файл не пройдёт валидацию Elysia.

### Валидация (article-media.ts)
- Фактический тип определяется **моникой магических байт** (JPEG: `FF D8 FF`; PNG: сигнатура; WebP: `RIFF`+`WEBP`; GIF: `GIF87a`/`GIF89a`) и сравнивается с заявленным `file.type` — заявленный `Content-Type` сам по себе не используется. Несовпадение или неизвестный тип → `400`, `Unsupported or mismatched image type`.
- Квота на артикль: не более `ARTICLE_IMAGE_MAX_COUNT = 50` файлов и не более `ARTICLE_IMAGE_TOTAL_MAX_BYTES = 100 МБ` суммарно (счётчик по уже сохранённым файлам в каталоге, кроме маркерного `.upload.lock`). Превышение → `400`.
- Запись выполняется с флагом `wx` против коллизий.

### Авторизация и владение
- **403** — пользователь не является автором статьи и не имеет `articles:manage` (`{ "error": "Forbidden" }`)

### Тело ответа
```json
{ "url": "/uploads/articles/1/image/<uuid>.png" }
```

### Возможные ошибки
- **401** — нет авторизации
- **403** — нет права на загрузку в эту статью
- **400** — неверный/несовпадающий тип файла, превышен максимальный размер (1 байт…10 МБ), превышена квота (50 файлов / 100 МБ суммарно)

## `POST /articles`
Создание статьи. При создании пишется начальная версия `1.0.0` и выполняется проверка контент-спама.

### Авторизация
Требуется `requireAuth`. Создание статей типа `STALHUB` доступно только пользователям с `articles:manage` (иначе `403`, `Only admins can create STALHUB articles`).

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `title` | Заголовок, ≤ 200 символов | `string` | Да |
| `content` | Содержимое, ≤ 50000 символов | `string` | Да |
| `type` | Тип статьи (`ArticleType`, по умолчанию `OTHER`) | `enum` | Нет |
| `image_url` | URL обложки | `string` | Нет |
| `quest_name` | Название квеста (только для `QUEST`), ≤ 200 | `string \| null` | Нет |
| `quest_type` | `QuestType`: `STORY` / `SIDE` (только для `QUEST`) | `enum \| null` | Нет |
| `quest_map` | Объект карты (валидируется `normalizeQuestMap`) | `any \| null` | Нет |
| `reward_text` | Текст награды, ≤ 5000 | `string \| null` | Нет |
| `reward_money` | Денежная награда, ≥ 0 | `integer \| null` | Нет |
| `flags` | Числовые флаги | `number` | Нет |
| `tags` | Массив тегов | `string[]` | Нет |

`quest_map` (валидация `normalizeQuestMap`): `map_id` (строка, непустая, ≤ 100 символов), опционально `map_name` (≤ 200) и `markers` — массив (≤ 100) маркеров `{ x: number, y: number, label?: string (≤ 200) }`; координаты должны быть конечными числами.

### Спам-лимит
`enforceContentSpam(user_id, SPAM_LIMIT_ARTICLE)` — 10 публикаций в час; при превышении срабатывает авто-бан (предупреждение → бан).

### Тело ответа
Структура совпадает с `list`-элементом, `views: 0`, `stars_count: 0`, `is_starred: false`.

### Возможные ошибки
- **401** — нет авторизации
- **400** — `title`/`content` обязательны; невалидный `quest_map`
- **403** — попытка создать тип `STALHUB` без `articles:manage`

## `PATCH /articles/:id`
Частичное обновление статьи. Разрешено автору или админу (`articles:manage`). Изменение `content` добавляет новую версию (метка `Date.now()`). Если итоговый тип не `QUEST`, все квест-поля сбрасываются в `null`.

### Авторизация
Требуется `requireAuth`.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id статьи | `number` | Да |

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `title` | Заголовок, ≤ 200 | `string` | Нет |
| `content` | Содержимое, ≤ 50000 | `string` | Нет |
| `type` | Тип статьи (`ArticleType`) | `enum` | Нет |
| `image_url` | URL обложки (можно `null` для очистки) | `string \| null` | Нет |
| `quest_name` | ≤ 200 | `string \| null` | Нет |
| `quest_type` | `QuestType` | `enum \| null` | Нет |
| `quest_map` | Объект карты | `any \| null` | Нет |
| `reward_text` | ≤ 5000 | `string \| null` | Нет |
| `reward_money` | ≥ 0 | `integer \| null` | Нет |
| `flags` | Числовые флаги | `number` | Нет |
| `tags` | Массив тегов | `string[]` | Нет |

### Тело ответа
Обновлённая статья (структура как в `list`-элементе, включая актуальные `stars_count`).

### Возможные ошибки
- **401** — нет авторизации
- **403** — попытка изменить чужую статью без `articles:manage` (`{ "error": "Forbidden" }`)
- **404** — статья не найдена

## `POST /articles/:id/comments`
Создание комментария к статье (или ответа на комментарий). Упоминания `@username` в тексте создают внутриигровые уведомления «Упоминание» получателям (кроме автора).

### Авторизация
Требуется `requireAuth`.

### Спам-лимит
`enforceContentSpam(user_id, SPAM_LIMIT_COMMENT)` — 5 комментариев в час.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id статьи | `number` | Да |

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `content` | Текст, ≤ 5000 | `string` | Да |
| `parent_id` | id родительского комментария (должен существовать на этой же статье) | `number` | Нет |

### Тело ответа
Созданный комментарий: `id`, `content`, `article_id`, `parent_id`, `created_at`/`updated_at`, `author { id, name, username }`.

### Возможные ошибки
- **401** — нет авторизации
- **400** — невалидный `parent_id` → `{ "error": "Parent comment not found" }` (статус `200` не используется; проверка в сервисе)

---

## `DELETE /articles/:id/comments/:comment_id`
Удаление комментария. Разрешено автору комментария или пользователю с `articles:manage`. Удаление родительского комментария каскадно удаляет ответы.

### Авторизация
Требуется `requireAuth`.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id статьи | `number` | Да |
| `comment_id` | Числовой id комментария | `number` | Да |

### Тело ответа
```json
{ "success": true }
```

### Возможные ошибки
- **401** — нет авторизации
- **403** — не автор и нет `articles:manage`
