# Barter

**Модуль рецептов обмена (бартера) по локациям-поселениям с самым дешёвым источником.**

## Общие сведения

- Данные держатся **в памяти** процесса и перезагружаются: при старте (при сбое — одна повторная попытка через 60 с) и раз в неделю, в среду в 00:00 по Москве (cron `barter-update`, `0 0 * * WED`, `Europe/Moscow`).
- Источники: `barter_recipes.json` из репозитория `EXBO-Studio/stalcraft-database` (ветка `main/ru`) и `listing.json` с CDN `cdn.stalhub.dev/db` (локальноименованные названия/иконки предметов).
- Из предложений (`offers`) сохраняются только денежные (`currency === 'money'`) и только с разрешимым составом: каждый требуемый предмет обогащается данными listing (сопоставление предмета в listing по хвосту пути `data`, id выводится из компонента пути после последнего `/`).
- «Лучший» рецепт по поселению выбирается по минимальному `settlementRequiredLevel` (коррелирует со стоимостью).
- Redis-кэш (`barter/cache.ts`, TTL 7 дней для рецептов и 4 дня для listing) существует в коде, но на момент написания **не импортируется** — живой маршрут работает полностью в памяти.

## `GET /api/v1/barter/:item_id`

Рецепты бартера для предмета: самый дешёвый вариант, все поселения, где предмет продаётся, и рецепты, которые его потребляют.

### Параметры (path)

| Поле     | Описание    | Тип      | Обязательный |
| -------- | ----------- | -------- | :----------: |
| `item_id`| ID предмета | `string` | Да           |

### Тело ответа

```json
{
  "settlement_required_level": "5",
  "settlement_titles": [
    { "ru": "Бар", "en": "Bar", "es": "…", "fr": "…", "ko": "…" }
  ],
  "used_in": [
    {
      "item_id": "…",
      "category": "…",
      "lines": { "type": "text", "text": "…" },
      "color": "…"
    }
  ],
  "recipes": [
    {
      "money": "12000",
      "items": [
        {
          "amount": 3,
          "lines": { "type": "translation", "key": "…", "args": {}, "lines": { "ru": "…" } },
          "category": "…",
          "color": "…"
        }
      ]
    }
  ]
}
```

- `settlement_required_level` — строка: уровень поселения у самого дешёвого варианта.
- `settlement_titles` — по одному объекту на каждое поселение, где предмет встречается; ключи локалей `ru`, `en`, `es`, `fr`, `ko`.
- `used_in` — предметы-рецепты, которые **потребляют** запрошенный предмет (`item_id`, категория из иконки, локализованное `lines`, `color`).
- `recipes` — все денежные альтернативы лучшего рецепта; `money` — строка с ценой, `items` — требуемые предметы (число штук, названия (`lines` — сообщение типа `text` или `translation`), категория, цвет).

### Возможные ошибки

- **404** — `{ "status": 404, "message": "Item not found" }` — предмет не торгуется ни в одном поселении.
