# Loadout

**Модуль снаряжения (экипировочных пресетов) пользователей.**

## Общие сведения

- Сущность `userLoadout` (таблица `user_loadout`): `user_id` (PK), `data` — непрозрачный JSON, формируемый и валидируемый клиентом (сервер его не разбирает), `is_public` (по умолчанию `false`), `updated_at`.
- `GET`-эндпоинты доступны с опциональной авторизацией (`requireOptionalAuth`) — анонимные запросы разрешены, но не получают приватных данных.
- `PUT` доступен только авторизованным (`requireAuth`) и работает только со своей учёткой — чужие loadout записать нельзя.

---

## `GET /api/v1/loadout`

Постраничный список публичных loadout по списку id.

### Гард

`requireOptionalAuth` — не обязателен.

### Параметры (query)

| Поле       | Описание                                  | Тип      | Обязательный |
| ---------- | ----------------------------------------- | -------- | :----------: |
| `user_ids` | ID пользователей через запятую            | `string` | Нет          |

Строка режется по запятым, каждый элемент приводится к числу; в запрос попадают только положительные целые числа (остальные молча отбрасываются). Пустой `user_ids` → пустой массив.

### Тело ответа

Массив только **публичных** loadout (приватные молча исключаются):

```json
[
  {
    "user_id": 1,
    "data": {},
    "is_public": true,
    "updated_at": "2025-01-01T00:00:00.000Z"
  }
]
```

### Возможные ошибки

Нет (публичный эндпоинт).

## `GET /api/v1/loadout/:user_id`

Одиночный loadout конкретного пользователя.

### Гард

`requireOptionalAuth` — не обязателен.

### Параметры (path)

| Поле      | Описание             | Тип      | Обязательный |
| --------- | -------------------- | -------- | :----------: |
| `user_id` | ID пользователя     | `string` | Да           |

### Тело ответа

Объект loadout (аналогичен элементу массива из списка).

### Возможные ошибки

- **404** — `{ "error": "Loadout is private or not set" }` — loadout не задан либо приватен и запрашивающий не является его владельцем.

---

## `PUT /api/v1/loadout`

Создание или полное обновление собственного loadout (upsert).

### Гард

`requireAuth` — обязательная авторизация.

### Тело запроса

| Поле        | Описание                               | Тип       | Обязательный |
| ----------- | -------------------------------------- | --------- | :----------: |
| `data`      | Данные loadout (клиентский формат)     | `any`     | Да           |
| `is_public` | Публичная видимость                    | `boolean` | Нет          |

Дефолт `is_public = false`.

### Тело ответа

Сохранённый (созданный или обновлённый) объект loadout.

### Возможные ошибки

- **401** — не авторизован.
