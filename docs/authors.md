# Авторы

**Модуль рейтинга авторов (author of the week/month).**

Рейтинг строится по суммарной популярности работ автора за период: просмотры билдов, одобренных статей и артов, а также количество публичных пользовательских tier list. Все эндпоинты **публичные** (без авторизации).

---

## `GET /api/v1/authors/week`

Получение автора недели и топ-3 авторов месяца.

### Тело ответа

```jsonc
{
  "week": {
    "user": { "id": 1, "name": "Имя", "username": "user" },
    "views": { "builds": 100, "articles": 50, "arts": 30, "tier_lists": 5, "total": 185 },
    "works": [
      {
        "kind": "build",
        "id": 1,
        "external_id": "a1b2c3d4",
        "title": "Название",
        "views": 100,
        "popularity": 100,
        "created_at": "2025-01-01T00:00:00.000Z",
        "author": { "id": 1, "name": "Имя", "username": "user" }
      }
    ]
  },
  "month": [
    {
      "user": { "id": 2, "name": "Имя2", "username": "user2" },
      "views": { "builds": 200, "articles": 100, "arts": 60, "tier_lists": 10, "total": 370 },
      "works": [ /* до 3 работ */ ]
    }
  ]
}
```

- `week` — единственный автор недели (или `null`, если за неделю нет данных).
- `month` — массив топ-3 авторов месяца.
- `views` — разбивка популярности по типам контента (`builds`, `articles`, `arts`, `tier_lists`) и общая сумма `total`.
- `works` — до 3 самых популярных работ автора за соответствующий период. Поле `kind` принимает значения `"build"`, `"article"`, `"art"`, `"tier_list"`. Для артов и статей присутствует `image_url`. Для tier list поле `views` равно 0, а `popularity` — количество записей в tier list.

### Возможные ошибки

Нет (публичный эндпоинт).
