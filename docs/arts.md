# Модуль /arts

**Галерея артов (fan-art, артбуки): CRUD, загрузка медиа-файлов, фильтрация по тегам/типу, звёзды, просмотры и комментарии.**

---

## Общие сведения

Все пути имеют префикс `/api/v1`.

**Права:**
- Постоянные эндпоинты (`GET /arts`, `GET /arts/mine`, `POST /arts`, `POST /arts/upload`) дополнительно защищены guard'ом `requireArtAuthor`: пользователь должен иметь право `art:author` **или** `art:manage` (иначе `403 Forbidden`).
- `PATCH`/`DELETE /arts/:id` и удаление комментариев доступны автору или пользователю с правом `art:manage` (для любого арта).
- `GET /arts` без права `art:manage` возвращает только собственные арты; `GET /arts/public` открыт без авторизации.
- `GET /arts/:id`, `GET /public`, `GET /:id/comments` — публичные (без токена); `GET /:id` использует `requireOptionalAuth` (персонализация `is_starred` и дедупликация просмотров по id пользователя).

**Тип арта (`ArtType`):** `DEFAULT`, `NSFW`.

**Внешний ID:** `external_id` — slug из заголовка (при его отсутствии — литерал `art`); `GET /:id` принимает slug или числовой id.

**Видимость/фильтры:** `/public` принимает список тегов (строка через запятую, подстрочный поиск по объединённой строке тегов) и тип арта.

**Теги:** хранятся одной строкой через запятую; при создании к пользовательским тегам добавляются авто-теги (имя/ник автора и тип медиа: `рисунок` или `анимация` — анимация определяется расширением URL `.mp4/.webm/.mov/.avi/.mkv`) и дедуплицируются.

**Медиа-загрузка:** `POST /arts/upload` принимает файлы типов `image/png`, `image/jpeg`, `image/webp`, `image/gif`, `video/mp4`, `video/webm` (без ограничения размера в коде) и сохраняет в `./uploads/arts/<uuid>.<ext>` (расширение берётся из имени файла, при отсутствии — `.png`). Возвращает `{ "image_url": "/uploads/arts/<uuid>.<ext>" }`.

**Просмотры:** `GET /:id` записывает просмотр с дедупликацией (авторизованный — по `user_id`; аноним — по `sha256(ip + user-agent)`), TTL 12 часов. Уникальный просмотр инкрементирует `views` и метрику `content_views_total{type="art"}`; возвращаемое `views` учитывает прирост.

**Спам-лимиты:** `POST /arts` — `enforceContentSpam(SPAM_LIMIT_ART = 10)` в час; создание комментария — `SPAM_LIMIT_COMMENT = 5` в час. При превышении — авто-бан (предупреждение → бан).

**Комментарии:** общее хранилище с комментариями статей (`articleComment`, поле `art_id`), двухуровневое: список возвращает топ-уровень с вложенными ответами. Создание проверяет, что `parent_id` существует на этом же арте. Упоминания `@username` создают уведомления «Упоминание».

## `GET /arts`
Список артов. Без права `art:manage` — только собственные арты; с правом видны все.

### Авторизация
`requireAuth` + `requireArtAuthor` (`art:author` или `art:manage`).

### Параметры (query)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `take` | Кол-во элементов (по умолчанию `24`) | `number` | Нет |
| `page` | Номер страницы (по умолчанию `1`) | `number` | Нет |

### Тело ответа
```json
{
  "data": [
    {
      "id": 1,
      "external_id": "slug",
      "type": "DEFAULT",
      "title": "Название",
      "description": "Описание",
      "image_url": "/uploads/arts/uuid.png",
      "tags": ["арт", "рисунок"],
      "views": 10,
      "author": {
        "id": 1,
        "name": "Имя",
        "username": "ник",
        "social_links": null
      },
      "stars_count": 3,
      "comments_count": 0,
      "is_starred": false,
      "created_at": "2026-01-01T00:00:00.000Z",
      "updated_at": "2026-01-01T00:00:00.000Z"
    }
  ],
  "total_count": 1,
  "page": 1,
  "take": 24
}
```
Сортировка — по `created_at` (убывание).

### Возможные ошибки
- **401** — нет авторизации
- **403** — нет прав `art:author`/`art:manage` или аккаунт заблокирован

## `GET /arts/:id`
Получение арта по числовому id или `external_id`-slug. Записывает дедуплицированный просмотр.

### Авторизация
`requireOptionalAuth` — доступно без токена; с валидным токеном заполняется `is_starred` и просмотр дедуплицируется по `user_id`.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id или slug `external_id` | `string` | Да |

### Тело ответа
```json
{
  "id": 1,
  "external_id": "slug",
  "type": "DEFAULT",
  "title": "Название",
  "description": "Описание",
  "image_url": "/uploads/arts/uuid.png",
  "tags": ["арт", "рисунок"],
  "views": 11,
  "author": {
    "id": 1,
    "name": "Имя",
    "username": "ник",
    "social_links": null
  },
  "stars_count": 3,
  "comments_count": 1,
  "is_starred": false,
  "created_at": "2026-01-01T00:00:00.000Z",
  "updated_at": "2026-01-01T00:00:00.000Z"
}
```
`views` учитывает прирост при уникальном просмотре; `comments_count` — число комментариев арта.

### Возможные ошибки
- **404** — арт не найден

## `POST /arts/upload`
Загрузка медиа-файла арта. Сохраняется в `./uploads/arts/<uuid>.<ext>`.

### Авторизация
`requireAuth` + `requireArtAuthor`.

### Параметры (body, multipart/form-data)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `file` | Медиа-файл | `file` | Да |

Допустимые MIME-типы: `image/png`, `image/jpeg`, `image/webp`, `image/gif`, `video/mp4`, `video/webm`. Расширение сохраняемого файла берётся из имени загружаемого файла (`path.extname`), при отсутствии — `.png`.

### Тело ответа
```json
{ "image_url": "/uploads/arts/<uuid>.png" }
```

### Возможные ошибки
- **401** — нет авторизации
- **403** — нет прав `art:author`/`art:manage`
- **400** — недопустимый тип файла (ошибка из `saveArtMedia`, выводится сообщение)

## `POST /arts`
Создание арта. Запускается проверка контент-спама.

### Авторизация
`requireAuth` + `requireArtAuthor`.

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `title` | Название, ≤ 200 | `string` | Нет |
| `description` | Описание, ≤ 2000 | `string` | Нет |
| `type` | Тип (`ArtType`, по умолчанию `DEFAULT`) | `enum` | Нет |
| `image_url` | URL медиа | `string` | Нет |
| `tags` | Массив тегов | `string[]` | Нет |

### Спам-лимит
`enforceContentSpam(user_id, SPAM_LIMIT_ART)` — 10 публикаций в час.

### Тело ответа
Созданный арт (структура как в `list`), `stars_count: 0`, `comments_count: 0`, `is_starred: false`. Авто-теги (`имя/ник автора`, тип медиа) объединены с пользовательскими.

## `PATCH /arts/:id`
Частичное обновление арта. Автор или пользователь с `art:manage`.

### Авторизация
Требуется `requireAuth`.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id арта | `number` | Да |

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `title` | ≤ 200 (можно `null` для очистки) | `string \| null` | Нет |
| `description` | ≤ 2000 | `string \| null` | Нет |
| `type` | `ArtType` | `enum` | Нет |
| `image_url` | URL медиа (можно `null`) | `string \| null` | Нет |
| `tags` | Массив тегов (заменяет строку тегов) | `string[]` | Нет |

### Тело ответа
Обновлённый арт (структура как в `list`).

### Возможные ошибки
- **401** — нет авторизации
- **403** — не автор и нет `art:manage` (`{ "error": "Forbidden" }`)
- **404** — арт не найден

## `POST /arts/:id/comments`
Создание комментария к арту (или ответа). Упоминания `@username` создают уведомления «Упоминание».

### Авторизация
Требуется `requireAuth`.

### Спам-лимит
`enforceContentSpam(user_id, SPAM_LIMIT_COMMENT)` — 5 комментариев в час.

### Параметры (path)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `id` | Числовой id арта | `number` | Да |

### Параметры (body)
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `content` | Текст, ≤ 5000 | `string` | Да |
| `parent_id` | id родительского комментария (должен существовать на этом же арте) | `number` | Нет |

### Тело ответа
Созданный комментарий: `id`, `content`, `art_id`, `parent_id`, `created_at`/`updated_at`, `author { id, name, username }`.

### Возможные ошибки
- **401** — нет авторизации
- **400** — невалидный `parent_id` → `{ "error": "Parent comment not found" }`
