# Цены артефактов

**Модуль цен артефактов, агрегированных по данным аукциона EXBO.**

## Общие сведения

- Для каждого артефакта подтягиваются лоты (buyout) с аукциона EXBO (до 200 лотов на предмет, регион RU).
- Цены группируются по уровню качества (0–6) и паттерну (0–15). Результат — `ArtifactAggregate` с ячейками (min/median/count), кривыми паттернов, кросс-коэффициентами качества и тирами.
- Агрегат хранится в in-memory кэше по регионам; запись защищена Redis-lock (`SET NX EX`, TTL 10 минут).
- При обновлении с нулевым числом проданных предметов планируется до 5 повторных попыток с интервалом 60 секунд.
- Обновление инициируется при старте сервера (`onStart`).
- Все пути под префиксом `/api/v1`.

---

## `POST /artifacts-prices/:region`

Возвращает цены запрошенных артефактов для указанного региона.

### Параметры пути

| Поле     | Описание       | Тип      | Обязательный |
| -------- | -------------- | -------- | :----------: |
| `region` | Идентификатор региона (только `RU`) | `string` | Да |

### Тело запроса (JSON, массив)

Массив объектов:

| Поле      | Описание                          | Тип      | Обязательный | Ограничения         |
| --------- | --------------------------------- | -------- | :----------: | ------------------- |
| `item_id` | Идентификатор артефакта (EXBO ID) | `string` | Да           | —                   |
| `qlt`     | Уровень качества                  | `number` | Да           | `0 ≤ qlt ≤ 6`      |
| `ptn`     | Паттерн (потенциал)               | `number` | Да           | `0 ≤ ptn ≤ 15`     |

### Тело ответа

| Поле        | Описание                                        | Тип                    |
| ----------- | ----------------------------------------------- | ---------------------- |
| `updated_at`| Время последнего обновления агрегата (ISO 8601)  | `string \| null`       |
| `region`    | Запрошенный регион                               | `string`               |
| `prices`    | Массив цен (по одному на каждый элемент запроса) | `ArtifactPriceResult[]`|

`ArtifactPriceResult`:

| Поле      | Описание                                               | Тип                                      |
| --------- | ------------------------------------------------------ | ---------------------------------------- |
| `item_id` | Идентификатор артефакта                                | `string`                                 |
| `qlt`     | Уровень качества                                       | `number`                                 |
| `ptn`     | Паттерн                                                | `number`                                 |
| `price`   | Цена (null, если не удалось определить)                | `number \| null`                         |
| `source`  | Источник цены: `'market'` (наблюдена на аукционе), `'estimate'` (рассчитана) или `null` | `'market' \| 'estimate' \| null` |
| `count`   | Количество лотов с наблюдаемой ценой (0 для estimate)  | `number`                                 |

### Цепочка определения цены (fallback)

Цена вычисляется следующим образом:

1. **Рыночная цена**: если для запрошенного `item_id`/`qlt`/`ptn` существует ячейка в агрегате — возвращается `min` цена лотов (`source: 'market'`).
2. **Оценка по кривой паттерна**: `base0` (медиана pattern-0, нормализованная) × коэффициент паттерна (`source: 'estimate'`).
3. **Оценка по.anchor-качеству**: если строка для запрошенного `qlt` отсутствует, используется нижнее доступное качество как якорь, умноженное на `qualityRatio` и коэффициент паттерна (`source: 'estimate'`).
4. **Оценка по тиру**: глобальная медиана для `qlt` × коэффициент паттерна (`source: 'estimate'`).
5. Если ни один шаг не сработал — `price: null`, `source: null`.

Коэффициент паттерна (`interpolateRatio`) — кусочно-линейная интерполяция по кривым паттернов; за пределами наблюдаемого диапазона экстраполируется по наклону последнего отрезка, ограничивается `max(2, lastRatio × 1.5)`.

### Возможные ошибки

- **400** — регион не входит в `SUPPORTED_REGIONS` (на данный момент только `RU`). Возвращается `{ updated_at: null, region, prices: [] }`.
- **503** — кэш для региона ещё не готов (нет агрегата). Возвращается `{ updated_at: null, region, prices: [] }`.
