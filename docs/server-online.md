# Server Online

**Модуль онлайна игроков по регионам и серверам.**

## Общие сведения

- Данные опрашиваются с лаунч-бэкендов, перечисленных через env (`LAUNCHER_SOURCES` — JSON-массив `{ region, url }`).
- Для каждого источника нужен Bearer-токен: он получается через `GET <base>/auth?<LAUNCHER_AUTH_QUERY>` (payload должен быть `{ type: "OK", token }`), хранится в памяти по регионам и обновляется по требованию (устаревший токен даёт пустой ответ — он ретраится после рефреша).
- Снапшоты пишутся в БД: cron `server-online-snapshot` каждые 5 минут (таблица `server_online_snapshots`: `region`, `server_id`, `online`, `created_at`; прунинга нет).
- При импорте модуля выполняется прогревание токенов всех источников. Любые ошибки (auth, HTTP, плохой payload) деградируют в пустые результаты и логируются — эндпоинты не падают.
- Авторизация не требуется.

## `GET /api/v1/server-online`

Последние показатели онлайна по каждому серверу.

### Тело ответа

```json
[
  {
    "region": "RU",
    "serverId": "s1",
    "online": 1250,
    "updatedAt": "2025-01-01T00:00:00.000Z"
  }
]
```

Берутся 100 самых свежих строк снапшотов, для каждой пары «регион + сервер» остаётся самое новое значение.

### Возможные ошибки

Нет (публичный эндпоинт).

## `GET /api/v1/server-online/history`

История онлайна, агрегированная в 5-минутные бакеты за заданный период.

### Параметры (query)

| Поле    | Описание              | Тип      | Обязательный |
| ------- | --------------------- | -------- | :----------: |
| `hours` | Период в часах        | `number` | Нет          |

Дефолт `hours = 24`. Границы бакетов округляются до 5 минут; в один бакет суммируется онлайн всех серверов внутри региона; снапшоты вне окна игнорируются.

### Тело ответа

```json
[
  {
    "region": "RU",
    "createdAt": "2025-01-01T00:00:00.000Z",
    "online": 4321
  }
]
```

### Возможные ошибки

- **422** — невалидное значение `hours`.
