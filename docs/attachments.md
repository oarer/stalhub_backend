# Прикрепления (Attachments)

**Модуль получения списка прикреплений (附件 / attachments) для оружия из игровой БД.**

Данные загружаются с CDN (`cdn.stalhub.dev`) в оперативную память и обновляются автоматически каждую среду в 00:00 по Москве. При старте сервера выполняется первичная загрузка (с однократным повтором через 60 с при ошибке).

- Все эндпоинты **публичные** (без авторизации).
- Каждый запрос инкрементирует метрику `attachmentsRequestsTotal`.

---

## `GET /api/v1/attachments/:weaponId`

Получение прикреплений для указанного оружия.

### Параметры (path)

| Поле       | Описание           | Тип      | Обязательный |
| ---------- | ------------------ | -------- | :----------: |
| `weaponId` | ID оружия в игровой БД | `string` | Да          |

### Тело ответа

```json
{
  "weapon": {
    "id": "weapon_ak74",
    "category": "...",
    "name": { "type": "translation", "key": "..." },
    "color": "..."
  },
  "total": 5,
  "attachments": [ { /* AttachmentItem */ } ]
}
```

- `weapon` — объект оружия (id, category, name, color). `name` — объект-перевод.
- `total` — количество совместимых прикреплений.
- `attachments` — массив объектов `AttachmentItem` с полной информацией о каждом прикреплении (infoBlocks и т.д.).

### Возможные ошибки

- **404** — оружие с указанным `weaponId` не найдено.
