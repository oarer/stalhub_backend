# Auction

**Тонкий прокси аукциона Stalcraft: лоты и история цен по регионам.**

## Общие сведения

- Запросы уходят напрямую в EXBO API через общий axios-клиент (`https://eapi.stalcraft.net`, таймаут 10 с, автоматически подставляется серверный `Authorization: Bearer <EXBO_TOKEN>`; HTTP 429 повторяется один раз без бек-оффа; прочие ошибки нормализуются как `{ status, message, details }`).
- Кэш **Redis**: ключ `auction:<lots|history>:<region>:<id>:<limit>:<additional>:<offset>`, TTL 5 минут. Каждая комбинация query-параметров кэшируется отдельно; параметры берутся «как есть», строками, без нормализации.
- Дефолты query (при отсутствии): `limit = 10`, `additional = true`, `offset = 0` — пробрасываются вышестоящему API в строковом виде.
- Метрика `auctionRequestsTotal` инкрементится только на промахи кэша (реальные обращения наверх).
- Данные ничем не гейтятся по региону — параметр `region` валидируется по enum (`RU`, `EU`, `NA`, `SEA`, `NEA`).

## `GET /api/v1/auction/:region/:id/lots`

Лоты предмета на аукционе.

### Параметры (path)

| Поле     | Описание               | Тип                  | Обязательный |
| -------- | ---------------------- | -------------------- | :----------: |
| `region` | Регион                 | `enum` (`RU|EU|NA|SEA|NEA`) | Да           |
| `id`     | ID предмета            | `string`             | Да           |

### Параметры (query)

| Поле        | Описание                | Тип      | Обязательный |
| ----------- | ----------------------- | -------- | :----------: |
| `limit`     | Лимит записей           | `string` | Нет          |
| `additional`| Доп. сведения о лотах   | `string` | Нет          |
| `offset`    | Смещение                | `string` | Нет          |

### Тело ответа

```json
{
  "total": 25,
  "lots": [
    {
      "itemId": "…",
      "amount": 1,
      "startPrice": 1000,
      "currentPrice": 1200,
      "buyoutPrice": 1500,
      "startTime": "2025-01-01T00:00:00.000Z",
      "endTime": "2025-01-02T00:00:00.000Z",
      "additional": { "qlt": 10, "ptn": 5 }
    }
  ]
}
```

- `total` — общее число лотов по данным вышестоящего API (не обязательно равно числу выданных после `limit`).
- `currentPrice` — опционально; `additional` — модификаторы артефакта (поля `ndmg`, `qlt`, `it_transf_count`, `upgrade_bonus`, `spawn_time`, `ptn`, `bonus_properties`, `stats_random`, `md_k`), присутствует не у всех лотов.

### Возможные ошибки

- **422** — недопустимый `region` или невалидные параметры.
- **4xx/5xx** — ошибка вышестоящего EXBO API в нормализованном виде `{ status, message, details }` (в кэш не пишется).

## `GET /api/v1/auction/:region/:id/history`

История цен предмета.

### Параметры (path)

| Поле     | Описание               | Тип                  | Обязательный |
| -------- | ---------------------- | -------------------- | :----------: |
| `region` | Регион                 | `enum` (`RU|EU|NA|SEA|NEA`) | Да           |
| `id`     | ID предмета            | `string`             | Да           |

### Параметры (query)

| Поле        | Описание                | Тип      | Обязательный |
| ----------- | ----------------------- | -------- | :----------: |
| `limit`     | Лимит записей           | `string` | Нет          |
| `additional`| Доп. сведения           | `string` | Нет          |
| `offset`    | Смещение                | `string` | Нет          |

### Тело ответа

```json
{
  "total": 40,
  "prices": [
    { "amount": 1, "price": 1100, "time": "2025-01-01T00:00:00.000Z", "additional": { "qlt": 10 } }
  ]
}
```

Поля записи истории: количество, цена, время, опциональные модификаторы артефакта.

### Возможные ошибки

- **422** — недопустимый `region` или невалидные параметры.
- **4xx/5xx** — ошибка вышестоящего EXBO API в нормализованном виде `{ status, message, details }` (в кэш не пишется).
