# Баланс

**Модуль отслеживания изменений баланса предметов между версиями игры.**

## Общие сведения

- Полный листинг скачивается с CDN (EXBO listing), хэшируется и сравнивается с предыдущим снимком.
- Текущий дифф хранится в `diff.json`; каждая запись также архивируется как `diff_<timestamp>.json` (максимум 5 последних архивов).
- In-memory кэш с TTL 60 секунд; при простое — читается из `diff.json`.
- При недоступности listing API отдаётся последний сохранённый дифф (сервис деградирует, но не падает).
- Одновременные запросы на обновление разделяют один промис (single-flight).
- Все пути под префиксом `/api/v1`.

---

## `GET /balance/diffs`

Возвращает текущий набор изменений баланса.

### Query-параметры

| Поле      | Описание                                                  | Тип       | Обязательный |
| --------- | --------------------------------------------------------- | --------- | :----------: |
| `refresh` | Если `true` — принудительно перезапрашивает EXBO listing  | `boolean` | Нет          |

### Тело ответа

| Поле      | Описание                                          | Тип               |
| --------- | ------------------------------------------------- | ----------------- |
| `items`   | Массив изменений (`ItemChange[]`)                 | `ItemChange[]`    |
| `total`   | Количество элементов                              | `number`          |
| `status`  | Статус сервиса (хэши и свежесть)                  | `StatusObject`    |

`StatusObject`:

| Поле    | Описание                                         | Тип              |
| ------- | ------------------------------------------------ | ---------------- |
| `loc`   | Хэш локального (старого) снимка (null при ошибке)| `string \| null` |
| `remote`| Хэш удалённого (нового) снимка (null при ошибке) | `string \| null` |
| `ref`   | Путь в listing repo (`merged/listing`)           | `string \| null` |
| `fresh` | Кэш младше 60 секунд                            | `boolean`        |

`ItemChange` (из `balance/types.ts`):

| Поле       | Описание                                     | Тип                |
| ---------- | -------------------------------------------- | ------------------ |
| `path`     | Путь к предмету (категория/id)               | `string`           |
| `category` | Категория (`weapon`, `armor`, `artefact` и др.)| `ItemCategory`   |
| `name`     | Локализованное название                      | `string`           |
| `color`    | Цвет редкости (опционально)                  | `string \| undefined`|
| `changes`  | Массив изменений статов                      | `StatChange[]`     |

`StatChange`:

| Поле       | Описание                       | Тип                              |
| ---------- | ------------------------------ | -------------------------------- |
| `label`    | Название стата                 | `string`                         |
| `oldValue` | Старое значение                | `string \| number \| null`       |
| `newValue` | Новое значение                 | `string \| number \| null`       |
| `type`     | Тип изменения                  | `'added' \| 'removed' \| 'changed'` |

### Возможные ошибки

Нет специфичных; при ошибке EXBO возвращается последний сохранённый дифф.

## `GET /balance/diffs/archive`

Возвращает список доступных архивных диффов.

### Параметры

Нет.

### Тело ответа

| Поле    | Описание                                   | Тип       |
| ------- | ------------------------------------------ | --------- |
| `total` | Количество архивных файлов                 | `number`  |
| `files` | Массив timestamp-строк (без префикса `diff_` и `.json`) | `string[]` |

Примеры строк в `files`: `2025-09-11_14-30-00`.

### Возможные ошибки

Нет специфичных.

---

## `GET /balance/diffs/archive/:timestamp`

Возвращает конкретный архивный дифф по timestamp.

### Параметры пути

| Поле        | Описание                                     | Тип      | Обязательный |
| ----------- | -------------------------------------------- | -------- | :----------: |
| `timestamp` | Timestamp из имени файла (например `2025-09-11_14-30-00`) | `string` | Да |

### Тело ответа

| Поле    | Описание                      | Тип            |
| ------- | ----------------------------- | -------------- |
| `items` | Массив изменений (пустой, если не найдено) | `ItemChange[]` |
| `total` | Количество элементов          | `number`       |

### Возможные ошибки

- **404** (логический) — архив с указанным timestamp не найден; возвращается `{ items: [], total: 0 }`.
