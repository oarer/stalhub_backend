# Корневые и общие эндпоинты

**Приветствие, статическая раздача `/uploads/*` и проверка здоровья. Маршруты этого файла находятся вне общего префикса `/api/v1` (кроме `/health`), детали см. в README → «Глобально».**

---

## `GET /`
Приветственное сообщение API, отдаётся как plain text.

### Тело ответа
```
Hi!
This API was created for https://stalhub.dev <3

By: https://github.com/oarer
```

## `GET /uploads/*`
Статическая раздача загруженных файлов из директории `uploads/`. Защита от path traversal: путь декодируется (`decodeURIComponent`), переразрешётся через `resolve` и проверяется, что результат остаётся внутри `uploads/` (через `relative`). Исключён из RPS-лимита.

### Параметры
| Поле | Описание | Тип | Обязательный |
| ---- | -------- | --- | :----------: |
| `*` | путь к файлу внутри `uploads/` (wildcard-сегмент) | `string` | Да |

### Тело ответа
При успехе возвращается сам файл.

### Возможные ошибки
- **400** — `Bad request` — ошибка декодирования/резолва пути
- **403** — `Forbidden` — путь выходит за пределы `uploads/` (path traversal)
- **404** — `Not found` — файл не существует

## `GET /api/v1/health`
Проверка здоровья сервиса. Доступен без авторизации и исключён из RPS-лимита (префикс `/api/v1/health`). Также разрешён для гостевых аккаунтов.

### Тело ответа
```json
{
	"status": "ok",
	"uptime": "12345",
	"timestamp": "2026-09-11T12:34:56.789Z"
}
```

### Поля ответа
| Поле | Описание | Тип |
| ---- | -------- | --- |
| `status` | всегда `ok` | `string` |
| `uptime` | аптайм процесса в секундах (без дробной части) | `string` |
| `timestamp` | текущее время в ISO 8601 | `string` |
